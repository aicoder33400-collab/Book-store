RMP Maktaba

Bibliothèque de la mosquée

Comment installer :

📱
Sur iPhone / iPad
Utilisez Safari
  1. Ouvrez cette page dans Safari
  2. Appuyez sur Partager (carré avec flèche)
  3. Choisissez « Sur l'écran d'accueil »
  4. Appuyez sur Ajouter
🤖
Sur Android
Utilisez Chrome
  1. Ouvrez cette page dans Chrome
  2. Appuyez sur le menu ⋮ (3 points en haut à droite)
  3. Choisissez « Installer l'application »
  4. Appuyez sur Installer
💻
Sur ordinateur
Chrome, Edge ou Brave
  1. Cherchez l'icône ⊕ dans la barre d'adresse
  2. Ou menu ⋮ → « Installer RMP Maktaba »
  3. Confirmez l'installation
